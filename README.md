# ai-reviewer-test

A test repository for experimenting with AI-powered code review tools.

## Overview

This repository is used to evaluate and test automated code review workflows powered by AI. It serves as a sandbox for exploring how AI assistants can assist with pull request reviews, code quality checks, and developer feedback.

## Getting Started

Clone the repository:

```bash
git clone https://github.com/muhammadAzeem0x000/ai-reviewer-test.git
cd ai-reviewer-test
```

## Contributing

1. Create a new branch for your changes.
2. Open a pull request against `main`.
3. The AI reviewer will automatically analyse your changes and provide feedback.
